⚙️ 턴 진행

  1. 손패 정리: 최대 3장 버림 → 4장까지 보충
  2. 카드 사용: MP를 소비해 행동 카드 사용
  3. 선택 행동: 살생 또는 대화 또는 시도 안 함 중 택1
  4. 휴식(성찰): MP+1 회복 또는 Karma-1(HP-3 소모) 또는 대화 토큰+1(HP-3 소모) 중 택1

⚔ 살생 (기본 비용 MP 1)

  • 주사위 3개를 굴려 1개라도 5 이상이면 성공
  • 성공: 상대 → 메아리 덱, Karma +1, 메아리 1장 공개
  • 실패: HP - 상대A 피해, 상대 덱으로 이동 후 메아리 단계 발생
  • Karma 7이상이면 살생 비용 +1

🗣 대화 (기본 비용 MP 2)

  • 주사위 1개(+ 토큰 소모 시 +주사위 1개)를 굴려 합이 (상대 R + 현재 Karma) 이상이면 성공
  • 성공: 상대 완전 제거, Karma -1, 대화 토큰 +1(대화 토큰은 토큰을 사용하지 않은 경우에만 보충)
  • 실패: HP - 상대A 피해, 상대 덱으로 이동. Karma 3이상이면 메아리 1장 공개

⏭ 시도 안 함

  • HP - 상대A 피해, 상대 덱으로 이동, 메아리 단계 발생

⚡ 메아리 단계

  • 현재 Karma 만큼 메아리 덱에서 공개 (최대 5장)
  • 공개된 카드의 Echo 효과 즉시 적용 후 덱 맨 아래로

📈 Karma 패널티

  • Karma 0~3: 없음
  • Karma 4~8: 매 턴 종료 HP -1
  • Karma 7이상: 살생 비용 +1
  • Karma 9이상: 매 턴 종료 HP -2

🃏 카드 사용 팁

  • 길게 누르기: 카드를 크게 확대하여 볼 수 있습니다
  • 카드는 손패 정리 후 카드 사용 단계에 사용 가능합니다
  • 경청과 중재는 같은 턴에 함께 사용할 수 없습니다
  • 침묵 카드는 메아리 단계에서만 사용 가능합니다
